# That Cube Again!

Juego de plataformas 2D diseñado para dispositivos móviles (*URJC 2023-2024*). La mecánica principal radica en resolver cada nivel interactuando con las funciones y sensores físicos del teléfono móvil (giroscopio, sensor de luz, conectividad, etc.).

## Integración de Sensores y Mecánicas

* **Controles Físicos y Táctiles:** Botones en pantalla, control mediante pantalla táctil y acelerómetro.
* **Sensores del Dispositivo:** Giroscopio (inclinación), sensor de proximidad (movimiento de plataformas) y sensor de luz (campo de visión).
* **Estado e Interacción Hardware:** Estado de carga de batería, conmutación de modo avión (gravedad), activación de Bluetooth (teletransporte) y botones de volumen.
* **Feedback:** Patrones de vibración hápitca para guiado en el escenario.

---

## Accesibilidad y Características

* **Patrones de Accesibilidad:** Sistema de pistas (*Helping Hand*), salto de nivel (*Bypass*), ajuste de volumen (*Slow It Down*) y guardado persistente (*Save Early, Save Often / Leave It There*).
* **Personalización:** Skins de personaje (Nuu/Buu) y almacenamiento persistente de datos y ajustes.
* **Estilo Visual:** Arte *Pixel Art* en tonos pastel.
